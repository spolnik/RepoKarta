Remote repositories and Maven Central: exact workflow
1. Acquire or syncOpen Admin â†’ Repositories. Approve a GitHub/GitLab repository, then use Sync whenever its remote HEAD changes.
2. Wait for the pinned scanA successful clone/fetch queues normal indexing. This workspace reads the verified commit only; it never queries a remote worktree directly.
3. Scope Maven declarationsSelect the repository and Maven. RepoKarta extracts group:artifact coordinates from committed Maven and Gradle files.
4. Check Maven CentralChoose Refresh stale package versions. Matching public coordinates go to search.maven.org; cached results then show the source registry and observation time per row.

Remote sync and registry refresh are deliberately separate: sync changes the commit-pinned declarations; refresh updates only external version observations. Neither action modifies the repository.
