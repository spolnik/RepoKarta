The first visual slice establishes the demo workspace, search, source browser,
and repository maps. The next chapters will use the same capture contract.

| Area | Planned chapter |
| --- | --- |
| Distributed systems | Service topology, evidence, unresolved targets, and runtime observations |
| Dependencies | Package inventory, versions, advisories, refresh, and SARIF export |
| Insights | Coverage, static analysis, trends, and imported evidence |
| Chat | Providers, context mentions, citations, recovery, and permissions |
| Living documentation | Planning, generation, review, freshness, and export |
| MCP and API | Setup, authentication, tools, bounds, and integration examples |
| Shared deployment | Authentication, authorization, SCIM, audit, acquisition, and storage |
| Operations | PostgreSQL, backups, diagnostics, cleanup, observability, and upgrades |
| Internals | Runtime composition, persistence, indexes, artifact lifecycle, and trust boundaries |

Every chapter is complete only when it has:

- an authored explanation and configuration section;
- at least one real local screenshot;
- a short, captioned workflow clip where motion adds value;
- a recorded RepoKarta commit and demo-repository revision;
- explicit ready, partial, stale, unsupported, and failure behavior where
  applicable.
