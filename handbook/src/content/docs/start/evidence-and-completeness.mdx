RepoKarta treats provenance as part of the answer. A result is useful only when
you can see where it came from and whether the relevant index was ready.

## A useful reading rule

When a result says **partial**, do not translate that into “no more matches.”
When a topology target says **unresolved**, do not rename it to the most
plausible nearby service. When Java navigation says **syntax**, do not describe
it as compiler-precise.

<Aside type="tip" title="The visible uncertainty is a feature">
	RepoKarta is most valuable during difficult investigations precisely because
	it distinguishes confirmed evidence from a useful but incomplete lead.
</Aside>
