<Aside type="note" title="Why full clones?">
	Full Git history lets RepoKarta demonstrate commit search, history, diffs,
	and revision-pinned browsing. Shallow clones hide much of that story.
</Aside>

## Start the local catalogue

<Steps>
1. Build RepoKarta’s browser assets.

   ```powershell
   npm --userconfig .npmrc --prefix web ci
   npm --prefix web run build
   ```

2. Start RepoKarta against the parent workspace.

   ```powershell
   go run ./cmd/repokarta serve -open=false C:\Users\jacek\Documents\GitHub
   ```

3. Open `http://127.0.0.1:7331` and watch the repository drawer. Repositories
   become useful independently; you do not need to wait for the entire fleet.
</Steps>
