## One system of evidence, four ways to work

RepoKarta is a local-first code-intelligence application. It searches a
repository fleet, reads exact revisions, assembles structural and distributed
maps, tracks dependency and quality evidence, generates living documentation,
and exposes the same facts to coding agents. The important part is not the
number of features—it is that every surface shares the same evidence contract.

<SystemFlow />

## A laboratory, not a toy repository

The examples deliberately mix three real systems. A single sample cannot show
the difference between package dependencies, service communication, runtime
observations, compiler-backed navigation, and cross-language investigation.

<DemoTriad />

## The complete product surface

This edition covers functionality that exists in the current RepoKarta code.
Generated answers, imported evidence, and optional providers are labelled as
such; the guide does not turn an unavailable integration into a screenshot
mock-up.
