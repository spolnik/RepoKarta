not silently substitute an uncommitted working-tree version.

## From result to investigation

<Steps>
1. Open a search result at the matching line.
2. Select or enter an identifier in the source-intelligence panel.
3. Choose definitions, references, implementations, routes, or callers.
4. Follow a result while keeping the repository and indexed revision visible.
5. Copy the citation when you need to share the exact evidence.
</Steps>

<Aside type="caution" title="An unreferenced symbol is not automatically dead">
	Framework injection, profiles, reflection, configuration, generated code,
	and missing compiler coverage can all hide a valid reachability edge.
</Aside>
