Maps turn indexed facts into a navigable system view. The graph is an
investigation surface, not an illustration: selecting a fact opens its
repository, path, layer, and supporting citations.

## Read a map deliberately

<Steps>
1. Choose one repository before moving to the broader fleet view.
2. Search for a package, route, entry point, or dependency by name.
3. Select the node and open the evidence drawer.
4. Use **Focus neighbors** to reduce visual noise.
5. Switch to list view when exact inventory is more useful than spatial
   relationships.
</Steps>

<Aside type="note" title="Package use is not a service call">
	The repository map and package inventory answer structural questions.
	Distributed topology separately models HTTP, gRPC, Kafka, database, and MCP
	communication between running components.
</Aside>
